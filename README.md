# 🤖 나만의 AI 비서 (하이브리드 · 노트북 + 안드로이드)

기존 `Jarvis-Desktop-Voice-Assistant`(jarvis.py)를 바탕으로, **정해진 명령은 즉시 처리**하고
**그 외 자유로운 대화는 Claude API로 답변**하는 하이브리드 방식으로 새로 만들었습니다.

가장 큰 변화는 "브라우저 기반"이라는 점이에요. 노트북에서 서버 하나를 띄우면, 노트북 화면에는
작은 팝업 창으로, 같은 Wi-Fi에 연결된 **안드로이드 폰 브라우저**에서는 똑같은 화면으로 접속해서
음성으로 대화할 수 있습니다. 네이티브 안드로이드 앱을 따로 만들지 않아도 되는 대신, 크롬 브라우저의
음성 인식·음성 합성 기능을 그대로 활용합니다.

**화면 디자인은 영화 아이언맨의 J.A.R.V.I.S. 스타일 HUD**로 만들었어요 — 화면 전체가 검은
배경이고, 가운데에 빛나는 파티클 구체가 떠서 천천히 회전하며, 상태에 따라(듣는 중/생각 중/
말하는 중) 움직임과 밝기가 달라집니다. 채팅창이나 말풍선, 입력창 없이 화면을 누르면 바로
핸즈프리로 대화가 시작되고, 마지막 질문/답변만 화면 하단에 조용히 떠올랐다 사라져요. 설정은
우측 상단의 아주 작은 "⋯" 아이콘 안에 숨겨뒀습니다.

## 📁 파일 구성

```
jarvis_hybrid/
├── app.py                 ← 백엔드(Flask): 명령 처리 + Claude API 연동
├── launcher.pyw            ← 부팅 시 실행되는 진입점(팝업창)
├── requirements.txt         ← 필요한 파이썬 패키지 목록
├── config.example.json      ← 설정 예시(최초 실행 시 config.json 자동 생성됨)
├── setup_autostart.bat      ← 부팅 자동 실행 등록
├── remove_startup.bat       ← 자동 실행 해제
├── templates/index.html     ← 채팅 화면
└── static/                  ← CSS, JS, 아이콘, PWA 매니페스트
```

## 🚀 설치 (노트북, Windows 기준)

### 1단계 — Python 확인
이미 Anaconda/PyCharm 등이 있는 걸 보니 Python은 설치되어 있을 가능성이 높아요.
명령 프롬프트에서 `python --version` 이 동작하면 OK입니다. 안 되면
https://www.python.org/downloads/ 에서 설치하고, **"Add Python to PATH"** 를 꼭 체크하세요.

### 2단계 — 패키지 설치
이 폴더에서 명령 프롬프트를 열고:
```
pip install -r requirements.txt
```

### 3단계 — 바로 실행해보기
```
python launcher.pyw
```
(또는 `pythonw launcher.pyw` 로 실행하면 콘솔 창 없이 조용히 뜹니다)

작은 팝업 창이 뜨면 성공입니다. `pywebview` 설치가 안 됐거나 실패하면 자동으로
기본 브라우저 창으로 대신 열립니다 (기능은 동일해요).

### 4단계 — API 키 설정 (선택, 자유 대화를 원한다면)
1. https://console.anthropic.com 회원가입 → API Keys → 새 키 발급 (`sk-ant-...`)
2. 화면 우측 상단의 작은 **"⋯"** 아이콘 클릭 → API 키 입력 → 저장
3. API 키가 없어도 "시간 알려줘", "농담해줘", "위키백과에서 OOO 찾아줘", "유튜브 열어줘" 같은
   정해진 명령들은 바로 동작합니다.

### 5단계 — 부팅 시 자동 실행
`setup_autostart.bat` 더블클릭 → 완료! 다음 부팅부터 팝업창이 자동으로 뜹니다.
해제하려면 `remove_startup.bat` 을 실행하세요.

## 📱 안드로이드 폰에서 사용하기

1. **폰과 노트북을 같은 Wi-Fi**에 연결하세요. (모바일 데이터 X, 반드시 같은 공유기)
2. 노트북에서 앱을 실행한 상태에서 우측 상단 **"⋯"** 를 눌러 설정을 열면 하단에
   `http://192.168.x.x:5050` 같은 주소가 보입니다. (LAN 주소)
3. 폰의 **크롬(Chrome)** 브라우저에서 그 주소를 입력해 접속합니다.
4. 화면을 한 번 탭하면 시작됩니다 — 이때 마이크 권한 허용 팝업이 뜨면 허용해주세요.
5. 이후로는 버튼 없이 그냥 말하면 됩니다. 크롬 메뉴(⋮) → **"홈 화면에 추가"** 를 하면
   앱처럼 아이콘으로 실행할 수 있어요.

### 방화벽 때문에 폰에서 안 열릴 때
Windows에서 `Windows Defender 방화벽 → 고급 설정 → 인바운드 규칙 → 새 규칙`으로
**포트 5050(TCP)** 을 허용해주세요. 또는 처음 실행 시 뜨는 "Windows 보안 경고"
팝업에서 **[액세스 허용]** 을 눌러도 됩니다.

### 참고
- 시스템 제어 명령(스크린샷, 앱 실행, 음악 재생, 종료/재시작)은 **보안상 노트북에서
  직접 실행했을 때만** 동작합니다. 폰에서 요청하면 "이 명령은 노트북에서만 가능해요"
  라고 안내해줍니다.
- "유튜브 열어줘", "구글에서 OOO 검색해줘" 같은 명령은 **요청한 기기 자신의 브라우저**에서
  새 탭으로 열립니다. 즉 폰에서 말하면 폰 브라우저가, 노트북에서 말하면 노트북 브라우저가 열려요.

## 🗣️ 사용 방법 (핸즈프리)

1. 화면을 한 번 탭/클릭하면 검은 화면 가운데 빛나는 구체가 나타나고 자동으로
   **"LISTENING"** 상태가 됩니다. 버튼을 누를 필요 없이 그냥 말하면 됩니다.
2. 말이 끝나면 구체가 **"THINKING"** → 답변할 때 **"SPEAKING"** 으로 바뀌고,
   화면 하단에 방금 대화 내용이 잠깐 떠올랐다 사라집니다.
3. 답변이 끝나면 자동으로 다시 "LISTENING" 상태로 돌아가서 계속 대화할 수 있어요.
4. 헤드폰 사용을 권장해요 — 스피커로 들으면 비서가 자기 목소리를 마이크로
   다시 들어버릴 수 있어요 (말하는 동안엔 마이크를 꺼두긴 하지만, 완전히
   막지는 못해요).
5. 음성 인식이 안 되는 브라우저에서는 화면 아래에 텍스트 입력창이 자동으로 나타나요.

**말해볼 수 있는 것들:**
- "지금 몇 시야?" / "오늘 날짜 알려줘" / "무슨 요일이야?"
- "위키백과에서 인공지능 찾아줘" / "wikipedia python"
- "유튜브 열어줘" / "구글에서 강아지 사진 검색해줘"
- "농담해줘" / "tell me a joke"
- (노트북에서만) "스크린샷 찍어줘" / "계산기 실행해줘" / "음악 틀어줘"
- (노트북에서만, 확인 필요) "컴퓨터 종료해줘" → "네" 라고 답하면 실행
- 그 외 무엇이든 자유롭게 물어보면 Claude가 답합니다 (API 키 필요)
- 역할 모드를 따로 고르지 않아도 돼요. 업무 얘기를 하면 전문적으로, 공부 얘기를 하면
  쉽게 설명하고, 힘든 얘기를 하면 공감부터 하는 식으로 대화 맥락에 맞춰 알아서 태도를
  바꿔가며 대응합니다. 필요하면 우측 상단 "⋯" 설정의 시스템 프롬프트에 원하는 성격을
  직접 적어 넣을 수도 있어요.

## 🛠 문제 해결

| 증상 | 해결 방법 |
|---|---|
| `python`이 인식 안 됨 | Python 재설치 시 "Add to PATH" 체크 확인 |
| 팝업창이 안 뜸 | `pip install pywebview` 로 설치 후 재시도. 그래도 안 되면 자동으로 브라우저로 열립니다 |
| 화면 아래 텍스트 입력창만 보이고 음성이 안 됨 | 음성 인식은 크롬(Chrome)/엣지(Edge) 브라우저에서만 지원돼요. 텍스트 입력으로도 똑같이 사용할 수 있어요 |
| 소리가 안 나요 | 화면을 한 번 클릭/탭했는지 확인하세요 (브라우저 오디오 정책 때문에 첫 클릭이 필요해요) |
| 비서가 자기 목소리에 반응함 | 헤드폰을 사용하거나 볼륨을 낮춰주세요 |
| 폰에서 접속 안 됨 | 같은 Wi-Fi인지, 방화벽에서 포트를 허용했는지 확인 |
| API 오류 401 | API 키를 다시 확인 (설정에서 재입력) |
| API 오류 429 | 사용량 한도 초과, 잠시 후 재시도 |
| 위키백과/스크린샷 명령이 "패키지 필요"라고 나옴 | `pip install -r requirements.txt` 를 다시 실행 |

## ⚠️ 보안 참고사항

이 앱은 같은 집/사무실 Wi-Fi 안에서 가족·개인 용도로 쓰는 걸 전제로 만들어졌고,
로그인이나 암호화 없이 LAN에 서버를 엽니다. 공유기 포트포워딩으로 외부 인터넷에
노출하지 마세요. `config.json`에는 API 키가 평문으로 저장되니 이 폴더를 다른 사람과
공유하거나 깃허브에 올릴 때 `config.json`은 반드시 제외하세요 (`.gitignore`에 이미
포함되어 있어요).
